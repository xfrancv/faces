# faces

## Repositories
- [farel](https://github.com/xfrancv/farel) Public Face Recognition Library providing API for our face recognition models.
- [facis](https://github.com/xfrancv/facis) Generic repo/template to train face predictors.
- [facis_identity](https://github.com/xfrancv/facis_identity) Training identity models.
- [facis_age_module](https://github.com/xfrancv/facis_age_module) Training age predictors.
- [crop](https://github.com/xfrancv/crop) Low level functions for face preprocessing.
- [Facial-Age-Estimation-Benchmark](https://github.com/paplhjak/Facial-Age-Estimation-Benchmark) Benchmarking age prediction.
- [face_identity_benchmark](https://github.com/xfrancv/face_identity_benchmark) Benchmarking identity models.
